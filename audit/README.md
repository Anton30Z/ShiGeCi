# Сверка словаря ShiGeCi

В `vocabulary.jsonl` одна строка на каждую из 5 363 записей HSK 1–6. Поле `cedict` показывает совпадение упрощённого написания и числового пиньиня с CC-CEDICT. У 14 сочетаний нет отдельной статьи. Например, 车上 складывается из 车 и локализатора 上.

`ruComparison` показывает результат поиска каждого русского варианта в китайско-русских источниках. `all glosses found` и `some glosses found` означают буквальное совпадение с источником после нормализации. Синонимы, падежи, пояснения и разная пунктуация могут помешать совпадению. Омоним может дать совпадение при другом значении. `compare senses` означает, что статья есть, но формулировки требуют смыслового сопоставления. `no entry` означает отсутствие отдельной русской статьи в использованных данных. В `matchedGlosses` перечислены найденные варианты. `editedGloss` отмечает слова из списка редакторских правок.

`topicEvidence` различает явное тематическое назначение, подбор по слову в основном английском толковании и сохранённую исходную тему. Темы служат для навигации в приложении. Многозначные слова могут относиться к нескольким темам, текущая модель хранит одну.

Восемь ручных мнемоник имеют приоритет. Для остальных слов карточка использует локальный материал `study`. Для одиночных знаков берутся известные графические компоненты, для сложных слов — составляющие их иероглифы. Глосса отдельного иероглифа даёт ориентир и может отличаться от его значения в составе конкретного слова. Соседи подбираются из базы по общему знаку, затем по ключу или теме. Учебная подсказка предлагает собрать знак или сравнить конкретную пару слов. Это автоматически составленные упражнения.

## Источники и воспроизведение

- Написание и чтение: [CC-CEDICT / MDBG](https://www.mdbg.net/chinese/dictionary?page=cc-cedict).
- Русские толкования для сверки: [БКРС](https://bkrs.info/p47), [Русский Викисловарь через Kaikki](https://kaikki.org/ruwiktionary/) и [LiudmilaLV/json_hsk](https://github.com/LiudmilaLV/json_hsk). Последний набор может иметь общие первоисточники с базой приложения.
- Графическое разложение: [Make Me a Hanzi](https://github.com/skishore/makemeahanzi), словарный файл на основе Unihan и CJKlib. Условия и файл лицензии находятся в `public/data`.

Для повторной сборки нужны Python 3, сжатая выгрузка CC-CEDICT, JSONL китайского (гуаньхуа) из русского Викисловаря, файл dictionary.txt проекта Make Me a Hanzi, ежедневная DSL-выгрузка БКРС в gzip и hsk.json из json_hsk. Опции и порядок обработки указаны в `scripts/build_vocabulary.py --help`. Команда обновляет шесть JSON-файлов и построчный отчёт. Исправления значений и тем находятся в `scripts/reviewed-words.txt`, `scripts/reviewed-topics.txt` и генераторе.
